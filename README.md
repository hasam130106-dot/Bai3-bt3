# 📁 BÀI 3 – ĐỌC VÀ GHI FILE BẰNG NODE.JS

## 1. Mô tả
Sử dụng module FS trong Node.js để tạo tập tin, ghi thông tin sinh viên, đọc nội dung và ghi nối thêm tên lớp vào cuối tập tin bằng `appendFile()`.

## 3. Code chương trình

Sử dụng các chức năng:
- `writeFileSync()`: Tạo file và ghi thông tin sinh viên.
- `readFileSync()`: Đọc nội dung tập tin.
- `appendFile()`: Ghi nối thêm tên lớp vào cuối tập tin.

## 4. Lệnh chạy chương trình

Mở Terminal tại thư mục BAI03 và nhập lệnh:

## 5. Kết quả

Sau khi chạy thành công:
- Tập tin `thongtin.txt` được tạo.
- Nội dung họ tên và mã sinh viên được ghi vào tập tin.
